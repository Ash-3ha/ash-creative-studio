## Project Overview

This website is a personal project where I combine website content management, landing-page structure, SEO fundamentals, and analytics tracking in one place.

### Objective

I wanted a portfolio that feels modern and focused on my career as a Digital Marketer and Visual Creative, while also acting as a live environment to apply Google Tag Manager, GA4, and Google Search Console workflows.

### My Role & Execution

- **Content & Structure:** Organized sections for About Me, Skills & Expertise, Experience at SPT Hospitals, Portfolio work, Notes, and direct Contact.
- **CMS Setup:** Configured editable fields for copy, experience highlights, tools, social reels, and portfolio entries so updates can be published without code changes.
- **SEO & Tracking:** Added unique page titles, meta descriptions, canonical links, structured JSON-LD data, XML sitemaps, and GTM event triggers for lead actions.

### Outcome

The site runs as a live, searchable personal portfolio with verified Google Search Console indexing and clean GA4/GTM event tracking.
