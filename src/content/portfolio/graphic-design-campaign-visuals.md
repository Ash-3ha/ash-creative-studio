**The starting point.** A hospital communicates in many places at once: Instagram feeds and stories, paid ads, event promotion and its website. Each place has a different shape and a different reader, yet the hospital has to look like one organisation in all of them.

**What I designed.** Reusable social media templates, paid ad banner layouts, campaign and event creatives, and visual assets for the website.

**How the designs work.** Hierarchy puts the main message first, then the detail, then the action. Typography is chosen for legibility at small sizes. Each design is adapted to every format it will run in, so a message built for a feed post still reads clearly as a story, a banner or a poster.

**What this shows.** Graphic design in a marketing role is a communication job. The message has to be clear first, and consistent second.
